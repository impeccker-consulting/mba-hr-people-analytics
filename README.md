# People Analytics Simulation Lab

Interactive simulations for the MBA HR People Analytics course (Impeccker Consulting), published week by week.

**Open the lab:** see the link under the repository's About section (the GitHub Pages address).

Every simulation is a single HTML file. You can open it online, or download it and run it offline in any browser.

|---|---|---|

| 2 | 3-4 | Workforce planning and employer branding |
| 3 | 5-6 | Talent attraction and acquisition |
| 4 | 7-8 | Onboarding and learning and development |
| 5 | 9-10 | Engagement and performance management |
| 6 | 11-12 | Internal mobility and succession planning |
| 7 | 13-14 | Compensation and attrition prediction |
| 8 | 15-16 | Attrition diagnosis and alumni rehiring |
| 9 | 17-18 | DEI, pay equity and ethics |
